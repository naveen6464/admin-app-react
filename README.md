### Tecosoft Admin Web

### Description:

This project serves as the administrative web interface for managing blogs and whitepapers

### Technologies Used:

1. ReactJS (v18.2.0)
2. Redux (v4.2.1)
3. React Router DOM (v5.3.0)
4. Bootstrap (v5.2.3)
5. Moment.js (v2.29.4)
6. Axios (v1.3.4)
Other libraries (see package.json for the complete list)



### Available Scripts:

1. npm start: Runs the app in development mode
2. npm run build: Builds the app for production
3. npm test: Runs tests
4. npm run lint: Runs linting
5. npm run lint-fix: Tries to fix linting errors
